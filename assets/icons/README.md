# Original Crystal Technology icons

Drop exported game PNG/WebP/JPG files into this directory. The Pages build matches `Pic` from Schema 300, including AssetStudio suffixes like `img_icon_CrystalResearch37_-123456.png`. Local files take precedence over verified web references. Missing images retain a fallback.

Priority missing original assets: `img_icon_CrystalResearch37` (Tough Skin), `img_icon_CrystalResearch38` (Drawn Blades), `img_icon_Research81` (Type 1034). `data/icon_sources.json` records the other sources. All original game art belongs to Lilith Games.
